# results/

Dated records behind every published number (plan §6.2 "Dated result records").

Layout: `results/<topic>/<YYYY-MM-DD>/`, holding the command that produced the result, the environment (OS, Python, git, agent versions) and the raw output.

Rules:
- Results are **aggregate or synthetic only**. Nothing here may contain transcript content, prompts, file contents or file paths from a user's machine.
- Never edit a result after the fact. Re-run and add a new dated folder instead.
