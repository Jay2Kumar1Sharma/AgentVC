# Code of Conduct

AgentVC adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in all project spaces (issues, pull requests, discussions, and any chat or event run by the project) and when representing the project elsewhere.

In short: be welcoming, be respectful, assume good intent, give and accept constructive feedback gracefully, and focus on what's best for the community. Harassment, insults, personal attacks and publishing others' private information are not acceptable.

## Reporting

Report unacceptable behaviour privately using GitHub's **Report content → Report to repository admins** option on the comment, issue or discussion in question. All reports are reviewed and handled confidentially. Maintainers who are involved in a report will not take part in handling it.

A dedicated contact email will be added here before AgentVC is released for use.

## Enforcement

Maintainers follow the Contributor Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): correction, warning, temporary ban, or permanent ban, depending on the impact of the behaviour.
