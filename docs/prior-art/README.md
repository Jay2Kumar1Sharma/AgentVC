# Prior art

One note per tool AgentVC learns from (plan §8 Discovery): `docs/prior-art/<tool>.md`.

Each note covers how the tool captures, stores and restores; what happens for (a) `rm -rf` run through the shell and (b) `git push` followed by an undo; its licence; and its limits. Anything not verified by reading source or running the tool is marked **inferred**, and source reads record the commit they read.

Notes are written in Discovery part 2 (`docs/agent-prompts.md`, session 2).
